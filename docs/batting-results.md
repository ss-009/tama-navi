# 打席結果と成績の計算

`src/domain/batting-result.ts` と `src/domain/stats.ts` の仕様。どちらも純粋関数で実装し、Vitest でテストする。

## 打球方向（fielder）

スコアブックの守備位置番号を使う。

| 番号 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 守備位置 | 投 | 捕 | 一 | 二 | 三 | 遊 | 左 | 中 | 右 |

- 打撃妨害は打席数にだけ数え、打数にも出塁率の計算にも含めない

## 成績の計算式

対象は `games.status = 'final'` の試合の打席のみ。

```
打席   PA  = 打席の数
打数   AB  = 打数に数える結果の数（上の表の「打数」列）
安打   H   = single + double + triple + home_run
塁打   TB  = single×1 + double×2 + triple×3 + home_run×4
四球   BB  = 四球 + 故意四球
死球   HBP = 死球
犠飛   SF  = 犠飛
犠打   SH  = 犠打
三振   SO  = 三振 + 振り逃げ
打点   RBI = 打点の合計

打率   AVG = H / AB
出塁率 OBP = (H + BB + HBP) / (AB + BB + HBP + SF)
長打率 SLG = TB / AB
OPS        = OBP + SLG
```

`game_players` から集計するもの:

```
試合   G   = 出場記録（game_players）の数
得点   R   = runs の合計
盗塁   SB  = stolen_bases の合計
盗塁死 CS  = caught_stealing の合計
```

### 表示ルール
- 分母が0のときは計算せず、`-` と表示する（NaN や 0 を出さない）
- 率は小数第3位まで表示し、1未満は先頭の0を省く（`.333`）。1以上はそのまま（`1.000`）
- 四捨五入する
- OPS は OBP と SLG を丸める前の値で足してから丸める

## テストケース（最低限）

| 打席 | AB | H | AVG | OBP | SLG | OPS |
|---|---|---|---|---|---|---|
| 安打, 四球, 三振, 犠飛 | 2 | 1 | .500 | .500 | .500 | 1.000 |
| 本塁打, 遊ゴ, 死球, 犠打 | 2 | 1 | .500 | .667 | 2.000 | 2.667 |
| 失策出塁, 野選, 振り逃げ | 3 | 0 | .000 | .000 | .000 | .000 |
| 四球, 打撃妨害 | 0 | 0 | - | 1.000 | - | - |
| 打席なし | 0 | 0 | - | - | - | - |

- 2行目の OBP: (1 + 0 + 1) / (2 + 0 + 1 + 0) = 2/3
- 4行目: AB = 0 なので AVG と SLG は `-`。OBP は (0 + 1 + 0) / (0 + 1 + 0 + 0) = 1。OPS は SLG が出せないので `-`

## 入力表記との変換

`src/domain/batting-result.ts` に次の2つを用意する。

```ts
// 保存形式 → 表示（例: { result: 'single', fielder: 7 } → '左安'）
formatBattingResult(result: BattingResult, fielder: Fielder | null): string

// 結果と方向の組み合わせが正しいか（方向の必須/なしのチェック）
validateBattingResult(result: BattingResult, fielder: Fielder | null): boolean
```

入力画面では文字列をパースせず、「結果」と「方向」をボタンで選ばせる（[spec.md](spec.md#打席一括入力最重要) 参照）。

## 能力ランク（遊び要素）

`src/domain/abilities.ts`。選手ページに S〜G で表示する。草野球向けにしきい値をゆるめにしている。

| 能力 | 指標 | S | A | B | C | D | E | F | 判定条件 |
|---|---|---|---|---|---|---|---|---|---|
| ミート | 打率 | .400 | .350 | .300 | .250 | .200 | .150 | .100 | 5打席以上 |
| パワー | 長打率 − 打率 | .300 | .230 | .170 | .120 | .080 | .050 | .020 | 5打席以上 |
| 選球眼 | (四球 + 死球) / 打席 | .20 | .16 | .12 | .09 | .06 | .04 | .02 | 5打席以上 |
| 走力 | 盗塁 / 試合 | 1.0 | 0.7 | 0.5 | 0.3 | 0.2 | 0.1 | 0より大きい | 1試合以上 |

- 値がその列以上ならそのランク。F に届かなければ G
- 判定条件に届かないときは `?` を出す

## 投手成績

`src/domain/pitching.ts`。試合ごとの登板記録（`pitching_appearances`）から計算する。対象は `status = 'final'` の試合のみ。

```
登板   G    = 登板記録の数
投球回      = アウト数 ÷ 3（表示は '5 1/3'）
防御率 ERA  = 自責点 × 7 ÷ 投球回          （草野球の7回制に合わせて7イニング換算）
WHIP        = (被安打 + 与四球) ÷ 投球回
勝率        = 勝 ÷ (勝 + 敗)
```

- 投球回0のときは防御率・WHIP を `-` にする
- 防御率・WHIP は小数第2位まで（四捨五入）
- 1試合のチェック: 同じ投手は1回だけ、自責点 ≤ 失点、勝ち・負けは各1人まで（両方はつかない）、セーブは勝ち試合に1人まで

## チーム成績

`src/domain/team-record.ts`。試合終了かつスコアが入っている試合を年ごとに数える（試合・勝・敗・分・勝率・得点・失点）。勝率 = 勝 ÷ (勝 + 敗)。

## 個人ランキング

`src/domain/ranking.ts`。上位3位まで、同じ値は同順位。0の人は載せない。

- 打率: 打席 ≥ その年の試合数 × 1
- 防御率（小さい順）: 投球回 ≥ その年の試合数 × 1回
